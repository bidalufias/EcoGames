- Official brand: `public/brand/mgtc-logo.png`; preserve the supplied identity.
- Favicon: `public/favicon.svg`.
- UI icon family: `src/ui/icons.ts`; pause, search, maximize, grid, play, arrowLeft, arrowRight, banana, battery, brain, cable, candy, car, carrot, check, cigarette, coffee, egg, factory, flame, footprints, gamepad, globe, heart, house, leaf, lightbulb, moon, newspaper, paint, pill, plug, puzzle, recycle, replay, salad, sprout, star, sun, thermometer, timer, toothbrush, trash, tree, trees, trophy, umbrella, user, volume, volumeOff, waves, x, zap, trainFront, cloudRain, haze, chevronDown, power, rotateCw, backspace, book, wholeWord, turtle, scale, building, shield, fish.
- Typography: self-hosted Plus Jakarta Sans Variable.
- Shared cover compositions: `src/ui/art.ts`; 12 game definitions in `src/games/registry.ts`, each used in hub tiles, featured covers, and introduction screens.
- Shared surfaces: `src/styles/tokens.css`, `base.css`, `components.css`, `shell.css`; light/dark palettes, buttons, cards, navigation, HUD, dialogs, toasts, covers, and focus states.
- Game-specific CSS: 12 game style files; boards, cards, letter keys, cables, feedback, and controls.
- Waste Sorter: procedural sky, ground, clouds, four bins and falling-item tokens in `SorterScene.ts`.
- River Rescue: procedural river, riverbanks, bushes, flowers, wake and ripples in `RiverScene.ts`.
- Turtle Trek: procedural beach, dunes, grass, tracks, nest, lamps, night overlay and animated surf in `TrekScene.ts`.
- Mangrove Guard: procedural mudflat grid, coast, mangrove roots, wave/flood overlays, health bars and effects in `GuardScene.ts`.
- Switch Off!: procedural floorplan, floors, walls, windows, doors and furniture in `HouseArt.ts`; five characters (You, Adik, Ibu, Abang, Atuk), each with 3 directions × 3 animation frames in `sprites.ts`; scene lighting and bubbles in `SwitchScene.ts`.
- Solar Link: generated SVG cable paths and powered states in its view/CSS.
- Eco Memory: card fronts, backs, match states.
- Eco Quiz: topic tiles, question/answer states and explanations.
- Grow the Forest: 11 growth-stage compositions reusing the central image library.
- Eco Word: guesses, clue, on-screen keyboard and feedback colors.
- Greener Choice: two image cards, feedback and explanations.
- Green City: buildings, empty cells, offer cards and placement previews.
- Shared effects: CSS transitions and `src/ui/confetti.ts`.

References are lexical consumers; content modules supply assets dynamically to game scenes. A source file listed here does not need modification to receive an image replacement.
